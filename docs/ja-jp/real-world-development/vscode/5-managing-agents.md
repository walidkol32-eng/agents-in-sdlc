VS Code の Copilot Chat でエージェントモードを使うと、Copilot はプロジェクトを調べ、変更を提案し、ファイルを編集して、コマンドを実行します。作業は自分のマシンでリアルタイムに進むため、ツール呼び出しやファイルの編集を Copilot Chat で確認できます。差分をインラインでレビューし、個々の変更を承認または破棄し、追加のプロンプトで会話の方向を調整できます。エディターを離れる必要はありません。

この演習では、次の内容を学習します。

- アクセシビリティエージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集をレビューして承認します。
- セッション中にエージェントへ指示し、ハイコントラストモードと並行してライトモードを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティカスタムエージェントが、ハイコントラストモードを実装しています。作業中にデザインチームから追加の依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライトモードの切り替え機能も追加します。新しい会話を始めるのではなく、既存のセッションに指示を追加して作業を拡張します。

## Copilot の進行状況を監視する

Copilot Chat ビューには、エージェントが実行する各ステップ、調べたファイル、実行したコマンド、提案する編集が表示されます。各ファイルの編集は、差分と **Keep** / **Undo** の操作とともにチャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、ツールの呼び出しを確認します。ファイルの読み込みや編集、実行を求めるターミナルコマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がチャット内に表示されます。
   - **Keep** を選択して変更を承認します。
   - **Undo** を選択して変更を元に戻し、別の方法で再度作業させます。
4. チャット上部の **Files changed** を開くと、このセッションで変更したファイルをすべて確認できます。

> [!NOTE]
> ターミナルコマンドの実行などに許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認し、許可してもよいコマンドだけを承認してください。

5. エージェントがハイコントラストモードの実装を終えるまで待ちます。最後に、行った変更の概要が表示されます。

## エージェントにライトモードを追加させる

ハイコントラストモードができたら、同じ会話でライトモードの切り替え機能を追加します。同じチャットセッションを続けることで、エージェントは先ほどの作業、変更したコンポーネント、スタイルの方針、local storage を使った設定の保存方法を引き継ぎます。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

   ```plaintext
   Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
   ```

2. エージェントは以前の変更を確認し、ライトモードを追加する提案をします。
3. ハイコントラストモードの場合と同じように、新しい編集をレビューします。各差分で **Keep** または **Undo** を選択します。
4. たとえば、好まない方法でトグル UI をリファクタリングするなど、エージェントの作業方針を変更したい場合は、チャット入力欄の横にある **Stop** ボタンで停止して、明確な追加プロンプトを送信します。

> [!TIP]
> 作業中のセッションに指示を追加する方が、最初からやり直すよりも速く進められます。「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使う」のような調整、「3 つ目のトグルを追加せず、既存の設定パネルにライトモードを統合する」のような方向修正、「両方のトグルにキーボードショートカットも追加する」のような範囲拡張を、追加プロンプトで依頼できます。

## 作業対象をレビューする

コミットする前に、エージェントが変更した内容を確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されています。
3. 変更されたファイルをいくつか開き、差分を確認します。ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保存など、カスタムエージェントのアクセシビリティの指針が反映されていることを確認します。
4. 内容に問題がなければ、Source Control パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードでセッションの進行を監視し、各ファイルの編集をレビューして承認または拒否し、コンテキストを保ったまま追加プロンプトで作業を拡張しました。

この演習では、次の内容を学習しました。

- エージェントの作業をリアルタイムで監視する方法。
- ファイル編集を個別に承認または拒否する方法。
- 作業中のセッションに追加プロンプトを送り、方向を調整する方法。
